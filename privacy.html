HLDS Privacy Policy

HLDS is a personal data synchronization tool. It uses Google Drive API to create, read, and manage application datasets and backups.

Data is used only for synchronization and backup purposes. Files may be transferred between the user's devices and configured backup storage providers.

HLDS does not sell user data or use it for advertising. OAuth credentials are stored in the user's configured local environments. Application files are not intentionally shared publicly.

Users can revoke Google Drive access through their Google Account security settings.
